# EZ Records — offline Flutter starter

This is a recreated starter ZIP for EZ Records, not a verified copy of the earlier archive. It contains a basic offline SQLite record-entry and history app for Android/iOS. It is **not** a compliance-certified application, and does not yet include PDF export, GPS, photos, automatic weather, backup, or in-app purchases.

## Build
Install Flutter, then from the folder containing pubspec.yaml run:

```sh
flutter create .
flutter pub get
flutter run
```

For iOS, a macOS build environment or compatible cloud build service and Apple signing are required. Review label requirements and applicable federal/state recordkeeping rules before relying on records for compliance.
